# ✈️ Travel Website

A responsive travel website developed using Angular, TypeScript, HTML5, and CSS3.

## 🚀 Features

- Responsive Navigation Bar
- Attractive Home/Hero Section
- Popular Destinations
- Travel Packages
- Travel Gallery
- Responsive Contact Form
- Responsive design for different screen sizes
- Modern UI with hover effects

## 🛠️ Technologies Used

- Angular
- TypeScript
- HTML5
- CSS3
